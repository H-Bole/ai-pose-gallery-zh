# 界面与图片查看规范

全站沿用现有中性明暗主题和公共组件，不为单个页面另建配色、字体或装饰系统。

## 字体与控件

- 字体使用全局 Inter Variable 与中文系统字体回退；Canvas文字使用相同字体名称。
- 页面标题：桌面24px、手机22px，字重600；章节及弹窗标题18px、600。
- 正文、按钮与控件标签14px；辅助信息、来源和编号12px。不使用9–11px装饰小字或扩张字距。
- 手机文字输入保留16px，避免iOS聚焦时自动放大；它与正文属于不同控件角色。
- 背景、文字、边框、选中和焦点使用既有语义颜色变量。按钮、输入框和对话框复用公共组件；图片操作及新增查看控件点击区域至少44px。
- 材质反光属于作品内容；编辑器外壳随全站明暗主题切换。

## 图片与通知

- 点击生成结果、历史或作品先查看大图。查看历史不改变当前结果；制卡从明确按钮进入。
- ZoomViewport的100%表示完整适应窗口，范围1–8倍；滚轮围绕指针缩放，放大后可拖移。键盘加减缩放、方向键平移、0或Home复位。
- 三图库保留自己的导航、角度、收藏与搭配操作，仅复用缩放区域。切图和尺寸变化复位。
- 二层卡面大图在关闭时保留编辑，Esc只关闭最上层并返回焦点。
- 通知沿用既有触发点。最多三条且受视口高度约束，余下排队；隐藏项暂停计时，通知区域不形成滚动列表。
