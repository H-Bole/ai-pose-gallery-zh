# 界面与图片查看规范

全站沿用现有中性明暗主题和公共组件，不为单个页面另建配色、字体或装饰系统。

## 字体与控件

- 字体使用全局 Inter Variable 与中文系统字体回退；Canvas 文字使用相同字体名称。
- 页面标题：桌面 24 px、手机 22 px，字重 600；章节及弹窗标题 18 px、600。
- 正文、按钮与控件标签 14 px；辅助信息、来源和编号 12 px。不使用 9–11 px 装饰小字或扩张字距。
- 手机文字输入保留 16 px，避免 iOS 聚焦时自动放大；它与正文属于不同控件角色。
- 背景、文字、边框、选中和焦点使用既有语义颜色变量。按钮、输入框和对话框复用公共组件；图片操作及新增查看控件点击区域至少 44 px。
- 材质反光属于作品内容；制卡工作台外壳随全站明暗主题切换。

## 图片、选图与制卡

- 点击生成结果、历史或作品先查看大图。查看历史不改变当前结果；制卡从明确的“制卡与分享”按钮进入。
- ZoomViewport 的 100% 表示完整适应窗口，范围 1–8 倍；滚轮围绕指针缩放，放大后可拖移。键盘加减缩放、方向键平移、0 或 Home 复位。三图库保留自己的导航、角度、收藏与搭配操作，仅复用缩放区域；切图和尺寸变化复位。
- 工作流图片入口隐藏浏览器原生文件控件，以“选择图片／替换图片”按钮操作；显示实际文件名与“已选择，生成时上传”，没有选择时说明可选状态或沿用工作流原图。读取期间禁用选择和清除，失败保留原图；可重复选择同一文件。清除后恢复对应空状态。
- 制卡采用全屏工作台，主预览旁设置“材质／版式／文字”页签；效果目录采用静态缩略图，提供分类、搜索与变体展开，不同时运行整屏动态预览。完整使用方法见[制卡工作台](card-workspace.md)。
- 二层卡面大图关闭时保留编辑，Esc 只关闭最上层并返回焦点。离开存在修改的制卡工作台时，明确选择保存、继续编辑或放弃本次修改。

## 连接与任务状态

- 已填地址或密钥只说明已配置。ComfyUI 明确显示未配置、尚未检测、检测中、HTTP 可达、连接失败或浏览器离线；最近检测时间与失败说明不暴露凭据。
- 仅在创作间或接口配置页使用 ComfyUI 时启用 HTTP 检测；前台可见时每 30 秒检测，8 秒超时。后台暂停，恢复可见或联网后检查，后台检测不弹通知。手动“检测连接”将检测中与结果更新为同一条通知。
- HTTP 可达与生成任务 WebSocket 状态分开表达。任务进度区继续显示任务实时连接与查询状态，采样百分比仅代表当前节点。
- “待确认任务”整段位于创作间右栏生成结果下方、生成历史之前；恢复跟踪不重复提交，“停止跟踪（不取消后端）”保留明确语义。

## 通知与导航

- 通知沿用既有触发点。最多三条且受视口高度约束，余下排队；只有实际可读的通知开始计时，隐藏项暂停，通知区域不形成滚动列表。
- 全站动态效果偏好尊重系统减少动态效果；关闭动效不阻止关闭通知、保存或其他必要操作。
- 侧栏标识与个人版一致，GitHub 和 X 分别使用对应图标；个人 X 入口为 [Xiaoyao_111](https://x.com/Xiaoyao_111)，与上游及素材作者归属链接区分。
