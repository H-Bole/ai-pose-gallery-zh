# 作品、配方与任务恢复

素材收藏按类别、来源和稳定 ID 区分，不绕过安全模式。图片负责查看，收藏与加入搭配位于独立操作栏。

## 生成后保存

当前结果和每条历史记录均可“保存作品”，无需制作卡牌。命名作品独立保存在“作品与搭配库”，不受最近30条历史裁剪影响。有生成快照时，作品保留当次参考、实际提示词、模型和参数；用户后来修改输入不会改变快照。

载入配方会明确提示替换当前编辑，保留当前连接地址和密钥，不会自动生成。实际提交图和种子已记录，载入仍沿用随机种子开关，不保证逐像素复现。旧历史没有完整配方时仍可保存图片、制卡、下载和继续创作；旧搭配保留载入能力，不伪造配方。

上传与成品引用保存在IndexedDB。写入失败会提示，不能认为浏览器清理站点数据后仍可找回；不提供云同步或完整备份。工作流JSON和提示词按原文保存，请勿在其中手写秘密。

## 可选卡面与动效

默认原图、无材质。成品查看器可选择原图/收藏卡/球员卡及无/闪箔/浮雕/全息，文字可留空。默认完整展示，可选择铺满并移动裁切。浮雕仅表现边框、文字和纹理，不生成立体人物。

下载原图保留原文件；分享PNG只绘制作品及所选卡面，不加入参考图、提示词或连接信息。卡框PNG长边2048px，原图模式保持原始像素尺寸。预览和PNG使用同一绘制逻辑，PNG为正视卡面。

动态效果提供自动/开启/关闭并记忆选择，尊重系统减少动态效果。触屏不依赖悬停、不拦截页面滚动。关闭动效不影响关闭通知或完成必要操作。

## ComfyUI任务恢复

获得prompt_id后保存任务编号、clientId、原地址和生成快照。刷新、页面激活及恢复联网时查询原任务，不重复提交。采样百分比仅代表当前节点，连接状态单独显示；WebSocket不可用时HTTP查询保底。

提交响应丢失显示结果未知，禁止自动重试/prompt。超时保留任务记录；“停止跟踪”不会取消共享后端任务。成品与历史写入成功后才清理活动记录，恢复同一任务不会重复添加历史。

远程WS鉴权使用固定comfyui及comfyui-auth.<访问令牌>子协议；网关须验证来源、路径、升级与凭据，只回显固定协议并剥离认证协议。令牌不进入URL或访问日志。不带密钥的原生连接不发子协议；部署配置单独维护。
