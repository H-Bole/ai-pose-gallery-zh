# 作品、配方与任务恢复

作品、配方与任务记录保存在当前浏览器，连接配置与参考快照分别维护。

素材收藏按类别、来源和稳定 ID 区分，不绕过安全模式。图片负责查看，收藏与加入搭配位于独立操作栏。

## 生成后保存

当前结果和每条历史记录均可“保存作品”，无需制作卡牌。命名作品独立保存在“作品与搭配库”，不受最近30条历史裁剪影响。有生成快照时，作品保留当次参考、实际提示词、模型和参数；用户后来修改输入不会改变快照。

载入配方会明确提示替换当前编辑，保留当前连接地址和密钥，不会自动生成。实际提交图和种子已记录，载入仍沿用随机种子开关，不保证逐像素复现。旧历史没有完整配方时仍可保存图片、制卡、下载和继续创作；旧搭配保留载入能力，不伪造配方。

上传与成品引用保存在IndexedDB。写入失败会提示，不能认为浏览器清理站点数据后仍可找回；不提供云同步或完整备份。工作流JSON和提示词按原文保存，请勿在其中手写秘密。

## 制卡与样式保存

当前结果、生成历史和作品库均有“制卡与分享”入口；点击作品图片本身仍查看大图。全屏制卡工作台提供材质、版式、文字页签，默认原图且无材质。常用项和完整静态缩略图目录共 83 项效果及变体，按分类和名称查找；旧卡保持原样，选新材质时才转换。

移动、播放或倾斜只试看光位，点击“采用当前光位”后才用于保存和导出。可从当前结果／历史保存到作品库，或为已有作品保存样式；卡面编辑不改变当次生成快照。未保存就退出时可继续编辑、放弃修改或保存并关闭，失败保留编辑。

“下载原图”保留原文件；“导出 PNG”长边 2048 px，绘制作品与所选卡面、材质及已采用光位，不带预览容器透视，不加入参考图、提示词或连接信息。具体操作、效果来源与旧卡兼容见[制卡工作台](card-workspace.md)。全站减少动态效果时仍可手动调整和完成保存。

## ComfyUI 连接检测

接口配置和创作间的状态以实际 HTTP 检测为准，仅填入地址或密钥不视为已连接。检测请求等待最多 8 秒，只有使用 ComfyUI 且页面可见时每 30 秒静默检查；后台暂停，恢复可见、联网或手动点击时再检查。修改地址或密钥后，旧请求的结果不会回写到新连接。

检测显示最近检查时间与安全的失败提示；手动检测只更新同一条通知，后台检测不弹通知。HTTP 可达只说明状态接口响应正确，不表示某个生成任务的 WebSocket 已连接；任务连接状态仍在生成进度区单独显示。

## ComfyUI 任务恢复

提交前建立WebSocket，获得prompt_id并保存任务编号、clientId、原地址和生成快照后立即核验历史。正常连接由事件更新进度与完成状态，HTTP每30秒核验一次；WebSocket不可用时改为每3秒查询。完成事件、重连、页面激活及恢复联网会立即核验原任务，不重复提交。采样百分比仅代表当前节点，WebSocket连接状态与HTTP查询错误分别显示。

创作间右栏在生成结果下方、历史之前显示“待确认任务”。提交响应丢失显示结果未知，禁止自动重试 /prompt。超时保留任务记录；可恢复原任务跟踪，或点击“停止跟踪（不取消后端）”清除本地跟踪记录，后端可能仍在执行，下次提交前应核对队列。成品与历史写入成功后才清理活动记录，恢复同一任务不会重复添加历史。

远程WS鉴权使用固定comfyui及comfyui-auth.<访问令牌>子协议；网关须验证来源、路径、升级与凭据，只回显固定协议并剥离认证协议。令牌不进入URL或访问日志。不带密钥的原生连接不发子协议；部署配置单独维护。
