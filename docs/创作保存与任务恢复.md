# 本地创作保存与 ComfyUI 任务恢复

收藏按素材类别、来源和稳定 ID 区分，人像、现实与二次元服装、姿势页均可取消收藏和筛选。收藏不会绕过安全模式。

合成台可命名保存、载入、改名和删除搭配；保存参考图、提示词、画风、工作流、模型选择及生成参数。上传图和附加图会写入浏览器 IndexedDB。载入不会替换当前连接地址及 API Key；工作流 JSON 与提示词按原文保存，请勿在其中手写秘密。随机种子仍按保存的开关执行，不保证载入后逐像素复现。

当前成品和历史成品可作为下一轮人像参考，保留其他参考和参数，不触发生成。成品下载或浏览器存储写入失败会明确提示；浏览器清理站点数据会删除这些本地内容，不提供云同步或完整备份。

ComfyUI 获得 prompt_id 后保存任务编号、clientId、原连接地址和提示词摘要。刷新、页面激活及恢复联网时查询原任务历史和队列；不会重新提交。进度中的采样百分比仅代表当前节点，连接状态单独显示。WebSocket 不可用时使用 HTTP 查询保底。

提交响应丢失会标为结果未知，禁止自动重试 /prompt。超时会保留活动记录，后端可能仍在运行。存在未决任务时，先恢复或明确停止跟踪；“停止跟踪”不会取消共享后端任务。成品和历史写入成功后才清理记录，恢复同一任务不会重复添加历史。

远程网关如需 WebSocket 鉴权，浏览器发送固定业务协议 comfyui 与 comfyui-auth.<访问令牌> 子协议；网关必须验证来源、路径、升级请求与凭据，只回显固定业务协议，并在转发前剥离认证协议。令牌不得放进 URL 或访问日志；协议需符合浏览器 token 字符约束。不带 API Key 的原生 ComfyUI 连接不发送子协议。网关配置由部署者单独维护，本仓库不包含个人令牌或本机配置。
