# 制卡工作台

为作品制作可保存、可导出的卡面。编辑在当前浏览器进行，不改变原图或生成配方。

## 进入与编辑

在创作间当前结果、生成历史或作品与搭配库点击“制卡与分享”。工作台铺满窗口，预览区旁提供“材质／版式／文字”三个页签；手机端按可用空间排列。点击作品图片本身仍进入大图查看。

- **材质**：默认“无材质”，保留作品原色。常用项直接可选；“浏览全部 83 项”可按名称搜索、按分类筛选，并在同族目录中展开变体。每项展示静态缩略图，选中后在主预览查看动态效果；83 项是效果及变体数，不表示 83 种独立材质原理。部分材质支持强度调节，并记忆该项最近设置的强度。
- **版式**：原图按作品比例完整展示；“留白”与“海报”提供卡框构图，可选完整展示或铺满卡面。铺满时可调整水平、垂直裁切位置。
- **文字**：卡名、称号、编号均可留空，属于卡面展示，不改变作品原有名称与生成配方。

“恢复原图展示”重置这次卡面编辑，仍需保存才会更新已保存样式。原作品、参考快照与生成设置独立保留。

## 预览与光位

鼠标在主预览上移动可试看光位；触屏可拖动，支持时也可主动开启“倾斜感应”。权限或设备不可用会提示，不影响其他编辑。主预览获得焦点后，方向键调整光位，Home 恢复已采用光位。

“播放光效”只用于查看变化，离开前台会暂停。全站减少动态效果时不自动播放，也不强制启用感应；仍可手动调整。倾斜、播放和试看光位不会自动写入样式，满意后点击“采用当前光位”，保存和导出才会使用此位置；也可展开“导出光位”直接调整。

“放大预览”打开当前试看位置的大图，关闭后回到原编辑。它可与已采用光位不同，不应据此判断导出使用了另一组参数。预览或导出失败会提示并保留编辑，可重试。

## 保存与导出

- 从生成结果或历史进入，可“保存到作品库”；从已保存作品进入可“保存样式”。只有保存成功才更新已保存状态，已有作品与生成快照保留。缺少可保存记录的图片入口仍可导出。
- 编辑未保存就关闭时，可继续编辑、放弃本次修改，或在可保存时保存并关闭；失败时保留编辑与错误提示。
- “下载原图”下载原作品文件；“导出 PNG”绘制卡面及所选材质，长边 2048 px，使用已采用光位，不带预览容器的透视倾斜。PNG 不加入参考图、提示词、API Key 或连接信息。

保存内容仍在当前浏览器；清理站点数据或更换域名不会自动迁移，不提供云同步。作品与旧配方的存储边界见[作品、配方与任务恢复](创作保存与任务恢复.md)。
